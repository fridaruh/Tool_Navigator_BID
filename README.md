# Tool Navigator - IDB 2025

**Tool Navigator** is an interactive tool designed to help professionals navigate the ecosystem of Artificial Intelligence and automation tools.

## Primary Objective

The primary objective of this tool is to **simplify technological decision-making** through a guided logical flow. It allows users to quickly identify which tool (such as Copilot, Power Automate, Perplexity, or ChatGPT) is best suited for their specific task, based on criteria such as structure, privacy, research requirements, and the type of deliverable.

## Educational Context

This tool was created strictly for educational purposes for the course conducted for the **Inter-American Development Bank (IDB)** during **2025**, taught by **Frida Ruh**.

It is part of a learning ecosystem focused on the adoption of emerging technologies and improving productivity in professional environments.

## Technologies

- **Structure**: Semantic HTML5
- **Styling**: Tailwind CSS (via CDN)
- **Logic**: Vanilla JavaScript
- **Typography**: Google Fonts (Google Sans, Roboto)

## Getting Started

To use the tool navigator:

1. Clone this repository or download the `index.html` file.
2. Open `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari).
3. Answer the interactive questions to receive a personalized recommendation.
